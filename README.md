# AI-Socratic-Dsa-Assistant
An AI-powered interactive Data Structures and Algorithms learning assistant that guides students using a Socratic teaching approach.
Instead of giving direct answers, the AI helps students build intuition through structured questioning and explanations.

## 🚀 Features

● AI-powered Socratic tutoring for DSA
● Conversational learning (chat-based interface)
● Context-aware responses using chat history
● Code input support for explanation-based learning
● Fast backend using FastAPI
● Modern frontend built with Next.js
● Deployed full-stack application

## Tech Stack

Frontend
 ● Next.js (React)
 ● TypeScript
 ● Tailwind CSS

Backend
 ● FastAPI
 ● Python
 ● Groq LLM API
 ● REST API architecture

Others
 ● Deployment (Render / Vercel)

## System Design

    Frontend (Next.js)
            ↓
    FastAPI Backend
            ↓
    Prompt Engineering Layer (Socratic Engine)
            ↓
    Groq LLM (AI Model)
            ↓
    Response returned to user
